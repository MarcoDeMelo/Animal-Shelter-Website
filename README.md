# Animal Shelter Website

A static animal shelter website built with HTML, CSS, and JavaScript.

## Overview

The website presents information about an animal shelter and provides visitors with information about the organization, available cats, volunteering, and ways to get in contact.

## Pages

* About Us
* List of Cats
* How to Volunteer
* How to Contact Us

## Features

* Multi-page website navigation
* Animal shelter information
* Volunteer requirements and information
* Cat listings
* Contact information
* Social media links
* JavaScript-powered footer date
* Custom CSS styling
* Animal imagery

## Technologies

* HTML
* CSS
* JavaScript

## Purpose

This project demonstrates foundational web development skills including semantic HTML structure, CSS styling, multi-page navigation, images, hyperlinks, forms of user interaction, and basic JavaScript functionality.
